# 版本支持矩阵 — 每个发行包支持什么

每个发行包按服务器版本单独编译。装好后，插件对每个来连接的客户端只会做三种处理：

- **✅ 直连放行**：客户端版本与服务器相同，数据原样直通，完整支持。
- **🔶 识别但不放行**：路由表认识这个客户端版本，但跨版本翻译规则还没补齐，默认拒绝并在日志里写明原因。以后补齐数据时**不需要换插件**，更新配置即可自动生效。
- **❌ 表外版本**：路由表不认识的客户端版本，直接拒绝。

## 为什么「跨版本翻译」目前全是暂无

跨版本进服 = 把 A 版本的包翻成 B 版本的包，需要三条数据同时到位：

1. 客户端版本的协议定义（包结构）
2. 服务器版本的协议定义
3. 两个版本之间的字段级翻译规则（包 ID 重映射、字段增删、物品/方块注册表等）

当前状态：路由、配置、编解码框架全部就绪；开源库直接提供 944 / 975 / 1001 三个版本的定义，其余 23 个要逐版本补；翻译规则表为空（0 对），所以跨版本客户端暂时会被明确拒绝而不是静默放行——这是刻意设计，防止玩家带着损坏的数据进服。
